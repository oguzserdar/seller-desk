# Security

Please report security problems privately, not in a public issue.

Use GitHub's **Report a vulnerability** button on this repository's Security tab. Include what you found, how to reproduce it, and what it affects. You will get a reply within a few days.

Seller Desk handles payments through PayPal. It never stores card details. The server, not the AI, decides whether a payment counts, and only after PayPal confirms it. Reports about payment checks, owner sign-in, the MCP connector and the demo desk are especially welcome.

Only the latest release is supported.
