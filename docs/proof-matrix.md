## Reproduce

Use Node 24+, pnpm 10.2.1, and a fresh checkout. Run `pnpm install --frozen-lockfile`, then `pnpm demo`. The generated owner password stays in your terminal; do not include it in public evidence.

For tests, provide `TEST_DATABASE_URL` pointing to a disposable PostgreSQL database with a name ending in `_test`. The test setup drops and recreates its public schema. Run `pnpm test`, `pnpm check`, and `NODE_OPTIONS=--max-old-space-size=4096 pnpm build` sequentially. Run the HTTP smoke scripts only against your fictional local demo.
